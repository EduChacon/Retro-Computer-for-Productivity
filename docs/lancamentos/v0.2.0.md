Retro Computer is a retro computer for productivity: the desktop of a 1990s PC, with the open source [Craft](https://artcraft.run/) apps, your files in an ordinary folder and Claude Code in the Command Prompt. This is the first published release.

## What's new in 0.2.0

- **English and Spanish**, besides Portuguese. Choose in Control Panel › Language (Automatic follows the system language). Every window, menu, dialog, the Help and the program catalog are translated, and the Craft apps that have a translated interface (WordCraft, for example) follow the same language.
- **Programs update when you open them.** Retro Computer checks for a new version of a Craft app when you open it and installs it first. In Add or Remove Programs you can choose to update automatically, to be asked first, or to never check. About 20 seconds after startup it also updates the programs that are not open. An update never installs an older version, and a program installed from a `.zip` file is never replaced by itself.
- **New version notices** for Retro Computer itself (checked once a day, shown once per version).
- **Linux on ARM64**: packages for the Raspberry Pi 3, 4 and 5 (64-bit Raspberry Pi OS). The usage guide explains how to start Retro Computer automatically when the device turns on.
- Fixes: the welcome file is created on the first use of a disk; the message icons now show in the notification balloons.

## Good to know

- The Craft apps are young (0.x versions) and need WebGPU or WebGL2. Without a usable graphics card, Retro Computer falls back to software rendering, which is slower.
- Claude Code needs a Claude subscription (Pro, Max, Team or Enterprise) or an API key, and officially 4 GB of memory.
- Your drive C: is the folder `Documents/Retro Computer` on your computer; nothing is deleted without your request (Trash and previous versions).
