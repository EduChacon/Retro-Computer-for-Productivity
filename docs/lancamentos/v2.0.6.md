Retro Computer 2.0.6 runs DOS in the DOSBox of Linux, much faster, when it is installed.

## New

- **DOS in the DOSBox of Linux.** On Linux, the DOS emulator built into Retro Computer was slow on older computers. With the DOSBox of Linux itself installed (DOSBox Staging from the Program Store, or `sudo apt install dosbox` in the Command Prompt), DOS now runs in it, in a window of its own (Alt+Enter makes it full screen). It works on a copy of the `C:\DOS` folder (or of the folder of the program you opened), and whatever changes goes back to the disk the same way as before: when you close DOS, with Save to Disk and every two minutes, with the previous version kept and deleted files in the Trash. Drive C: is the only one it sees: the MOUNT command is turned off, so a batch file cannot reach the other folders of the computer. The DOS window of Retro Computer shows the Show DOS, Save to Disk and Close DOS buttons, and Options › Use DOSBox for Linux goes back to the DOS inside Retro Computer. Without DOSBox, Options › Install DOSBox for Linux opens the Program Store with it.
