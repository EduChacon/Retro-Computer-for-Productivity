Retro Computer 2.0.7 fixes the two screens in full screen on Windows and updates the Craft apps installed on Windows itself.

## Fixed

- **Two screens on Windows.** With "Use both screens in full screen" (Control Panel › Appearance › Settings), Retro Computer stayed on one monitor on Windows. The cause was the full screen of Windows itself: every time a full-screen window is moved or resized, it goes back to the monitor that holds most of it, and the change of scale between monitors (a notebook at 125% and a monitor at 175%, for instance) goes through the same path. On Windows, the desktop now covers the monitors without that full screen, with the title bar above them, out of view; it goes back to its place if something moves it. F11 still goes back to the window, and a video or a website in full screen stays on the monitor of the pointer. A new test runs this on the Windows of the build, with two monitors of different sizes.

## New

- **The Craft apps installed on Windows.** The Craft apps installed on Windows with their official installers (.msi), outside Retro Computer, do not update themselves. On Windows, Add or Remove Programs now has a **Craft on Windows** tab with each one's version. **Update** downloads the installer of the new version for the same processor (x64, x86 or ARM64) from the official release on GitHub, checks the SHA-256 digest that GitHub publishes (without it, nothing is installed) and the digital signature, which has to be the same maker's as the installed program, and runs the official installer, unchanged; Windows asks for the administrator confirmation. The administrator process copies the installer to a folder that only an administrator can change and checks the digest and the signature again right before installing. It never goes back to an older version, never installs a Craft app that was not installed, and leaves the portable copies alone. About 20 seconds after Retro Computer starts, a notice says when there is a new version.
