Retro Computer is a retro computer for productivity: the desktop of a 1990s PC, with the open source [Craft](https://artcraft.run/) apps, your files in an ordinary folder and Claude Code in the Command Prompt. Version 1.0 turns it into a complete everyday computer, and on Linux it can now be the computer's whole system, which makes it a good fit for an old laptop or a mini PC.

## What's new in 1.0

### Linux as the system
- **The "Retro Computer" session** on the Linux login screen (installed by the `.deb` package): the computer opens straight into Retro Computer, without the Linux desktop underneath. Shut Down really turns off, restarts and suspends the computer, or signs out. You can also skip the login screen at power-on (LightDM).
- **Linux programs on the taskbar**: the windows of Linux programs show up next to Retro Computer's, with their icons; click to bring them forward or minimize, right-click to pin or close.
- **Linux programs (Flathub)**: a new tab in Add or Remove Programs with the most popular programs and the categories of Flathub, search, details, install (per user, no password), update and remove.
- **Linux Updates** in the Control Panel: what needs updating (security updates marked), install everything with the administrator password, and optional daily automatic security updates. A balloon tells you once a day when updates are waiting.
- **Accents as on Windows with the US international keyboard**: ' + c gives ç, and the combinations Windows does not join write both characters (" + B = "B), also in Firefox; with other layouts, the ç works too.
- **Keyboard, mouse and touch**: the logo key opens Start, the volume, brightness and calculator keys work, Print Screen takes screenshots, tap-to-click on the touchpad, the keyboard layout in Control Panel › Keyboard (Brazilian ABNT2, US international with dead keys and more), the mouse side buttons go back and forward, and windows can be moved and resized by touch.

### Everyday work
- **Firefox as the default browser**, with the Retro Computer look (the gray, the raised borders, the square tabs and the Katica font) and a profile of its own, so your usual Firefox stays as it is. Control Panel › Internet chooses Firefox, the Retro Computer Browser or (outside the Linux session) the main computer's browser; on Linux without Firefox, it installs it from Flathub. Copy-protected streaming services play in Firefox.
- **A desktop you arrange**: choose the icons you want (the Command Prompt is no longer there by default) and add shortcuts to any program. The **Start menu is configurable** too: pin programs at the top, hide items, use small icons, keep or clear the recent documents, all in Taskbar and Start Menu Properties.
- **Explorer preview pane** for Word documents, PDFs, spreadsheets, OpenDocument text, plain text and pictures, and **Quick access** with your pinned folders.
- **Work journal**: one `.txt` per day in Documents, written by you and, if you want, noting each finished focus session and each changed file; it only adds lines.
- **Backup** of drive C: (with the Trash and the previous versions) to an external drive or another folder, daily, weekly or right away; it only adds and updates.
- **Full focus mode**: during a focus session, Do not disturb turns on and, if you choose, the games wait for the breaks.
- **Files both ways with the main computer**: Computer › Main computer shows its desktop, documents, downloads, pictures, music and videos, which work like a USB drive (copy in, copy out, nothing deleted or overwritten there). From the other side, Retro Computer can join the Windows **Send to** menu, and on a Mac you can drop files on its Dock icon or use **Open With**; a copy lands in Documents › Received. Control Panel › Drive C: › Main computer also puts a drive C: shortcut on the main computer's desktop.
- **Default program for each file type**: right-click › Open with › **Choose program…**, with "Always use this program", and the list in Control Panel › Default programs.
- **Special folders with their own icons** in Explorer (Desktop, Documents, Received, Work journal, Screenshots, Pictures, Music, Videos, Downloads, DOS).
- **Ask Claude** on the right-click menu: review, summarize or translate a file, or organize a folder; the current version of the file is kept first. And the **Character Map**.

### Claude adjusts Retro Computer
- Ask Claude Code in plain words ("make the background navy", "put the Calculator in the Start menu", "install WordCraft") and it changes the appearance, the taskbar, the Start menu, the sounds, the language, the shortcuts and the programs, through a local MCP server of Retro Computer with a new code at each start. What it deletes goes to the Trash; the password, the API key, the disk folder and the updates stay out of its reach, and Claude Code asks before each change. Control Panel › Claude › Adjustments turns it off.

### Several users
- **Control Panel › Users**: each person gets their own desktop, settings, lock screen password, Browser favorites and cookies, Work journal and drive C:; the installed programs are shared. With more than one user, Retro Computer asks who is using it when it opens, and **Start › Log Off** (or "Close all programs and log on as a different user" in Shut Down) switches. Removing a user never deletes files.

### More programs
- **DOS** (Start › Programs › Accessories › DOS): the DOSBox emulator built in, working offline. Double-click a DOS `.com`, `.bat` or `.exe` on drive C: to run it; what the program changes comes back to the disk, with the previous version kept.
- **Windows programs on Linux** through WINE (the system's or the one from Flathub, offered when missing): double-click an `.exe` or `.msi`; Start › Programs › Windows Programs lists what the installers created.
- **Checkers** (Brazilian or English rules) and **Chess**, against the computer at three levels or between two people; the game is kept when you close the window.

### A complete computer
- **Sounds › Audio**: choose the sound output and the microphone.
- **Power Options** (when the screen turns off and the computer sleeps, and what the lid does) and **Date and Time** (internet time and the time zone), in the Retro Computer session.
- **Accessibility Options**: high contrast, the magnifier, the large cursor, visual alerts and, in the session, sticky keys and mouse keys.
- **Multiple screens**: duplicate, extend or use only one (in the session); otherwise, which monitor Retro Computer uses.
- **Portable mode**: with a `Retro Computer (dados)` folder next to the program (the Windows `.zip`, the AppImage or the Mac app), the settings, the programs and drive C: stay in it, so everything travels on a USB drive.
- **On-demand antivirus** (ClamAV on Linux, Microsoft Defender on Windows) from the right-click menu; nothing is deleted on its own, and what is found can go to the Trash. On Linux, a USB drive can also be **formatted** (exFAT or FAT32).

### Windows, shortcuts and the screen
- **Magnetic corners**: drag a window to the left or right edge for half of the screen, to a corner for a quarter, or to the top for the whole screen; the logo key with the arrow keys does the same (also for Linux windows in the Retro Computer session).
- **Windows shortcuts**: Alt+Tab with the icon box of the period, Alt+F4, and the logo key with a letter (E Explorer, R Run, D desktop, M minimize all, I Control Panel, S search, V clipboard, L lock), a number (the pinned programs) or Shift+S (capture a piece of the screen). With Retro Computer as the Linux system they work everywhere, also with a Linux program in front; as an application, Windows, macOS and the Linux desktop keep many of them.
- **Ctrl + mouse wheel** zooms the text in Notepad, the Browser and the Command Prompt, and the icons in folders.
- **Screen resolution** (Control Panel › Appearance › Settings, in the Retro Computer session), with the 15-second "keep this setting?" of the period.
- **Night light**: warmer colors with less blue, from 8 PM to 7 AM (or all day), with the strength you choose.

### Ideas from the Linux distributions
A survey of the most used Linux systems (Linux Mint, Zorin OS, Pop!_OS, Ubuntu, Fedora and others) brought in what helps everyday work without changing the character of the project:
- **Clipboard history** (logo + V, or Accessories › Clipboard): the last 25 texts copied in any program, in memory only, without what password managers mark as secret; paste, pin, delete and clear.
- **Calculations in the search box**: type `12*3.5`, `200 × 15%` or `√2`; the result comes first, and Enter copies it.
- **Power modes** in the battery box (power saver, balanced, performance, on Linux).
- **Firewall** in the Control Panel (Linux, ufw), turned on with the administrator password.

### Security and privacy
- **Security Center** (Control Panel › Security): the lock screen password, the firewall, the automatic security updates and how the Claude key is stored, in one place, each with the button to its settings.
- **Secure connections only (HTTPS)** in the Browser, on by default: `http://` addresses open in the secure version, and a site without one shows a warning first (home network devices are left out).
- **Delete the browsing data when Retro Computer closes** (optional).
- In the Retro Computer session, the **Linux keyring** (GNOME Keyring) keeps the Browser cookies and the Claude key encrypted.
- A security review of the code: the main process only answers the desktop page itself, a Craft program only saves where you chose, and compressed folders have size limits and cannot leave links pointing outside them.
- A final security audit before 1.0: files from drive C: shown by the desktop (an `.svg`, an `.html`) run in a sandbox without access to Retro Computer, the desktop cannot be loaded inside a frame, a Craft program can only reach its own files and asks before reading the clipboard, the Craft downloads are checked against the SHA-256 published by GitHub, programs and scripts downloaded by a Craft are refused, opening a program on the main computer asks first, and links on drive C: cannot point outside it. Files taken to the main computer keep the "downloaded from the internet" mark. The main computer's folders are reached only by the desktop, never by Craft programs, Browser pages or DOS.

### The taskbar and the tray
- **Search box and pinned programs** next to Start, as on today's PCs; window buttons with names, or icons only grouped by program.
- **The tray**: Wi-Fi networks (Linux), volume, battery with screen brightness and low battery notices, the battery of wireless mice and keyboards, Bluetooth (Linux), notifications with Do not disturb, and the calendar on the clock (optionally with the date under the time).
- **Lock screen with a password** (Start › Lock the Computer), also when waking from sleep, when leaving the screen saver and when opening Retro Computer.

### Internet
- **Browser** with favorites, search, downloads, zoom, Find and Print; camera, microphone, location, notifications and screen sharing ask for permission site by site.
- **E-mail**: your web e-mail in a window of its own.
- **Sites as programs**: File › Install as Program turns a site into a program with its own icon and window.

### Built-in tools
- **Image Viewer** (zoom, rotate, print, slide show) and **Media Player** (videos and music from the disk, subtitles, full screen, media keys).
- **Screenshot** (screen, window or a piece) and **System Monitor** (Ctrl+Shift+Esc: programs, processes and performance).
- **Calculator** and the games **Solitaire**, **Minesweeper** and **Breakout** (and Checkers and Chess, above).
- **Focus** now also has a **stopwatch** and a **timer**.
- **USB drives and memory cards** in Computer: open, copy in and out, and safely remove; nothing on them is overwritten.
- **Compressed folders**: a `.zip` opens like a folder; Extract all (also `.tar`) and Send to › Compressed folder.
- **Explorer** with a folders bar, a clickable address and thumbnails.
- **Printers** (default printer, print queue, test page) and **Bluetooth** (find, pair, connect, forget; the pairing code shows on the screen).
- **Computer programs**: the programs installed on the main computer, with shortcuts on the desktop and in Start.

### Updates and speed
- Retro Computer now **updates itself**: on Windows and with the AppImage it downloads the new version and installs it on restart; the `.deb` asks for the administrator password; on macOS, the notice opens the download page.
- **Lighter start**: twelve programs load only when they open (or while the computer is idle right after starting), and in the Retro Computer session the taskbar hears about Linux windows at once instead of asking every second and a half.

On macOS, open System Settings › Privacy & Security › Open Anyway the first time (up to macOS 14, right-click the app › Open › Open also works); on Windows, choose "More info" › "Run anyway" on the SmartScreen screen. The [installation guide](https://github.com/EduChacon/Retro-Computer-for-Productivity/blob/main/docs/instalacao.md) (in Portuguese) covers each case: Windows, macOS, an old Mac such as a 2014 MacBook Air with Linux Mint, a virtual machine in UTM, an old laptop or mini PC, and the Raspberry Pi.

## Good to know

- The Browser plays YouTube and the usual video and music sites, but not services with copy protection (Netflix, Prime Video, Disney+, Spotify on the web), and the Media Player does not play HEVC (H.265) or AVI files. For those, use the main computer's browser (on Linux, Firefox or Chrome from the Linux programs tab).
- macOS 12 Monterey or newer is required (Electron, the base of Retro Computer, dropped macOS 11). On an older Mac, install Linux and use the Retro Computer session (see the installation guide).
- The Linux session needs X11 (it uses Openbox); a Wayland session does not list the Linux windows nor take the global keys.
- The hardware features on Linux (Bluetooth pairing, printers, Wi-Fi, updates, power modes, the firewall, the resolution) were tested with simulated outputs of the system tools; the Linux windows on the taskbar, window docking and the global keys were also tested with Openbox and real X windows. Please report anything that behaves differently on a real computer.
- The Craft apps are young (0.x versions) and need WebGPU or WebGL2. Without a usable graphics card, Retro Computer falls back to software rendering, which is slower.
- Claude Code needs a Claude subscription (Pro, Max, Team or Enterprise) or an API key, and officially 4 GB of memory.
- Your drive C: is the folder `Documents/Retro Computer` on your computer; nothing is deleted without your request (Trash and previous versions). Each additional user has a folder next to it, such as `Documents/Retro Computer - Ana`. Users keep apart the desktops and documents of the people who share the computer; they do not hide the files from whoever uses the main computer.
- In the Retro Computer session, changing the language or the user now reopens Retro Computer inside the session.
- DOS is the DOSBox emulator as compiled by [js-dos](https://js-dos.com/) (package `emulators` 8.5.2, GPL-2.0), shipped unmodified and running isolated from the rest of the app; its source code is at <https://github.com/js-dos/emulators/tree/v8.5.2> and DOSBox's at <https://sourceforge.net/projects/dosbox/>. No DOS games or programs are included.
