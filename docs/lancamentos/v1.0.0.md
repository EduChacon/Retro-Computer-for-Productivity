Retro Computer is a retro computer for productivity: the desktop of a 1990s PC, with the open source [Craft](https://artcraft.run/) apps, your files in an ordinary folder and Claude Code in the Command Prompt. Version 1.0 turns it into a complete everyday computer, and on Linux it can now be the computer's whole system, which makes it a good fit for an old laptop or a mini PC.

## What's new in 1.0

### Linux as the system
- **The "Retro Computer" session** on the Linux login screen (installed by the `.deb` package): the computer opens straight into Retro Computer, without the Linux desktop underneath. Shut Down really turns off, restarts and suspends the computer, or signs out. You can also skip the login screen at power-on (LightDM).
- **Linux programs on the taskbar**: the windows of Linux programs show up next to Retro Computer's, with their icons; click to bring them forward or minimize, right-click to pin or close.
- **Linux programs (Flathub)**: a new tab in Add or Remove Programs with the most popular programs and the categories of Flathub, search, details, install (per user, no password), update and remove.
- **Linux Updates** in the Control Panel: what needs updating (security updates marked), install everything with the administrator password, and optional daily automatic security updates. A balloon tells you once a day when updates are waiting.
- **Keyboard, mouse and touch**: the logo key opens Start, the volume, brightness and calculator keys work, Print Screen takes screenshots, tap-to-click on the touchpad, the keyboard layout in Control Panel › Keyboard (Brazilian ABNT2, US international with dead keys and more), the mouse side buttons go back and forward, and windows can be moved and resized by touch.

### The taskbar and the tray
- **Search box and pinned programs** next to Start, as on today's PCs; window buttons with names, or icons only grouped by program.
- **The tray**: Wi-Fi networks (Linux), volume, battery with screen brightness and low battery notices, the battery of wireless mice and keyboards, Bluetooth (Linux), notifications with Do not disturb, and the calendar on the clock (optionally with the date under the time).
- **Lock screen with a password** (Start › Lock the Computer), also when waking from sleep, when leaving the screen saver and when opening Retro Computer.

### Internet
- **Browser** with favorites, search, downloads, zoom, Find and Print; camera, microphone, location, notifications and screen sharing ask for permission site by site.
- **E-mail**: your web e-mail in a window of its own.
- **Sites as programs**: File › Install as Program turns a site into a program with its own icon and window.

### Built-in tools
- **Image Viewer** (zoom, rotate, print, slide show) and **Media Player** (videos and music from the disk, subtitles, full screen, media keys).
- **Screenshot** (screen, window or a piece) and **System Monitor** (Ctrl+Shift+Esc: programs, processes and performance).
- **Calculator** and three games: **Solitaire**, **Minesweeper** and **Breakout**.
- **Focus** now also has a **stopwatch** and a **timer**.
- **USB drives and memory cards** in Computer: open, copy in and out, and safely remove; nothing on them is overwritten.
- **Compressed folders**: a `.zip` opens like a folder; Extract all (also `.tar`) and Send to › Compressed folder.
- **Explorer** with a folders bar, a clickable address and thumbnails.
- **Printers** (default printer, print queue, test page) and **Bluetooth** (find, pair, connect, forget; the pairing code shows on the screen).
- **Computer programs**: the programs installed on the main computer, with shortcuts on the desktop and in Start.

### Updates
- Retro Computer now **updates itself**: on Windows and with the AppImage it downloads the new version and installs it on restart; the `.deb` asks for the administrator password; on macOS, the notice opens the download page.

| System | File |
|---|---|
| Windows | `Retro-Computer-1.0.0-win-x64.exe` (installer) or `Retro-Computer-1.0.0-win-x64.zip` |
| macOS | `Retro-Computer-1.0.0-mac-arm64.dmg` (Apple Silicon) or `Retro-Computer-1.0.0-mac-x64.dmg` (Intel) |
| Linux (PC) | `Retro-Computer-1.0.0-linux-amd64.deb` or `Retro-Computer-1.0.0-linux-x86_64.AppImage` |
| Linux (Raspberry Pi, 64-bit) | `Retro-Computer-1.0.0-linux-arm64.deb` or `Retro-Computer-1.0.0-linux-arm64.AppImage` |

The installers are not digitally signed yet. On macOS, right-click the app › Open › Open the first time; on Windows, choose "More info" › "Run anyway" on the SmartScreen screen. To use Retro Computer as the Linux system, install the `.deb` (`sudo apt install ./Retro-Computer-1.0.0-linux-amd64.deb`) and choose the "Retro Computer" session on the login screen.

## Good to know

- The Browser plays YouTube and the usual video and music sites, but not services with copy protection (Netflix, Prime Video, Disney+, Spotify on the web), and the Media Player does not play HEVC (H.265) or AVI files. For those, use the main computer's browser (on Linux, Firefox or Chrome from the Linux programs tab).
- macOS 12 Monterey or newer is required (Electron, the base of Retro Computer, dropped macOS 11). On an older Mac, install Linux and use the Retro Computer session: see the installation guide (docs/instalacao.md, in Portuguese).
- The Linux session needs X11 (it uses Openbox); a Wayland session does not list the Linux windows nor take the global keys.
- The hardware features on Linux (Bluetooth pairing, printers, Wi-Fi, updates, the Linux windows on the taskbar) were tested with simulated outputs of the system tools; please report anything that behaves differently on a real computer.
- The Craft apps are young (0.x versions) and need WebGPU or WebGL2. Without a usable graphics card, Retro Computer falls back to software rendering, which is slower.
- Claude Code needs a Claude subscription (Pro, Max, Team or Enterprise) or an API key, and officially 4 GB of memory.
- Your drive C: is the folder `Documents/Retro Computer` on your computer; nothing is deleted without your request (Trash and previous versions).
