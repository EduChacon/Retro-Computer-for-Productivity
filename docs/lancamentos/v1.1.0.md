Retro Computer 1.1.0 brings tabs to the Browser, a program store on Windows and the Mac, a taskbar you can rearrange, and fixes for what came up with 1.0.

## New

- **Browser tabs and favorites bar**: each tab has its own page, the site icon and the title. Ctrl+T, Ctrl+W, Ctrl+Tab, Ctrl+Shift+T, Ctrl+1 to 9, the middle click and "Open link in new tab" work as in today's browsers, and the windows that sites open become tabs. The star in the address bar saves and removes favorites, shown on the favorites bar (Ctrl+Shift+B).
- **Picture in picture**: right-click a video › Watch in picture in picture, or View › Picture in picture (Ctrl+Shift+P). The small window stays on top of everything, also with the Browser minimized.
- **Status bar hidden by default** (View › Status bar); without it, the address of the link under the mouse shows in a small box in the corner of the page.
- **Program store on Windows and the Mac**: Add or Remove Programs has a second tab with the computer's own programs, from official sources only: **winget** on Windows (only its official source; some programs ask for Windows confirmation to install) and **Homebrew** on the Mac (the apps with windows; without Homebrew, the tab installs it through the Command Prompt). Search, see each program's details, install, update, remove and open. Installed programs show the computer's own icon; the others, the icon published on each program's official site. Linux keeps Flathub.
- **Rearrange the taskbar** by dragging the buttons: the pinned programs and the window buttons, with names or icons only. The order of the pinned ones is saved.
- **Program shortcuts in folders**: a program icon dragged from the desktop into a folder becomes a shortcut file in it (with Ctrl, it also stays on the desktop); double-clicking it opens the program.
- **Drag files out to the main computer**: files and folders from drive C: can be dropped on the main computer's desktop or folders, on a website (an e-mail attachment) or in another program. The main computer gets a copy; nothing leaves drive C:.
- **Real icons of Windows programs and shortcuts** in Start › Programs › Computer programs, on the desktop, on the taskbar and in the main computer's folders.
- **Claude** opens with a light background (the Command Prompt keeps the dark one, and the window bar switches between them), and Claude Code gets the matching theme and Retro Computer's language for the session, without changing what you chose in Claude itself.

## Changes

- **Opening**: the desktop opens directly, without the BIOS and logo screen (Control Panel › Appearance › Settings brings it back).
- **Password at opening**: with a password, Retro Computer asks for it when it opens, as Windows does (Control Panel › Passwords turns it off).
- **Automatic pixel size** follows the system scale without leaving the screen smaller than 1024 × 720 (at 150% on a 1920 × 1080 monitor, the windows did not fit).

## Fixes

- **Claude's text in the terminal**: letters were pushed to the left of their cells ("vári as") and some symbols were missing. The terminal fonts were rebuilt from SerenityOS with the right margins and the symbols Claude Code uses.
- **The Trash icon** now looks empty when the Trash is empty (the empty one also had papers).
- **Signing in to Google**: if Google still refuses the Browser, it now tries again on its own, presenting itself another way; if Google refuses both, it suggests Firefox as the default browser (Control Panel › Internet), which signs in normally.
- **The preview pane** of the Explorer no longer goes past the window.
- The notice that a program had no new version, when updating it, did not show.
