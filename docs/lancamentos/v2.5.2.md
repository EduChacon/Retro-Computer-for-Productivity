# Retro Computer 2.5.2

- Windows integrated apps follow their Retro frame while dragging. The integration panel shows only the controls after attachment. The native surface tells the Windows shell when it represents Retro in full screen, keeping the Retro taskbar accessible without globally hiding the Windows taskbar.
- Desktop shortcuts are included in Computer programs. Shortcuts with unreadable installer targets are passed to the Windows shell. Apps running as administrator receive a specific explanation and an option to show the existing original window, without relaunching the app or elevating Retro. This does not add support for embedding elevated apps such as some eSAJ installations.
- Recommended programs now include TextureCraft, Craft Anything and SolidCraft. The list checks the official Craft app table every six hours while open, with a manual refresh and an offline cache. New entries require an official browser release; discovery never installs apps automatically.
- New files can be created from the desktop and Explorer: Word documents, spreadsheets, presentations, Markdown, RTF, HTML, JSON and source files for C, C++, C#, Python, Rust and Java. Office files contain valid document packages; source files start with a small template. Existing files are preserved when names collide.
