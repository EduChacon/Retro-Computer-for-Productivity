# Retro Computer 2.5.1

Fix Windows integrated opening when a shortcut starts a launcher or updater and the actual app window belongs to another executable.

- Open the original shortcut through Windows and track the launched process and its descendants. Shortcut arguments and application identities are preserved. Squirrel-style `--processStart` shortcuts wait for the requested app instead of attaching the updater's temporary window.
- Allow up to 30 seconds for a stable app window, refresh the available windows on another attempt and prioritize windows belonging to the current launch.
- Recognize AppUserModelID metadata and expand Windows environment variables in shortcut targets. The Windows desktop and taskbars are excluded from window candidates.
- Add checks with real Notepad and Chrome, both through direct shortcuts and through a launcher that displays a temporary window and exits. The packaged Windows app also exercises Chrome with a dedicated temporary profile and a local page.

Window embedding remains experimental and depends on each application's behavior. See [the integrated apps guide](../programas-integrados.md).
