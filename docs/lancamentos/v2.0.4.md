Retro Computer 2.0.4 fixes the tabs of Firefox, makes the frame of the Linux programs follow the pixel size, and opens the E-mail and the installed sites in Firefox, so that the Google sign-in works.

## Fixed

- **An empty gap among the Firefox tabs.** A closed tab stayed as an empty space the size of a tab; now the other tabs close the gap, as usual.
- **The title bar of the Linux programs was too small** (Retro Computer as the system). The title bar, the buttons and the borders of the windows of Firefox, LibreOffice and the other Linux programs now grow with the pixel size of Control Panel › Appearance, with the same 18-point title bar and the same button drawings (minimize, maximize, restore, close) as the windows of Retro Computer.
- **The sign-in to the E-mail failed.** Google refuses the sign-in in browsers built into apps. With Firefox as the default browser, the E-mail and the sites installed as programs now open in a new Firefox window, with the sign-ins you have there.
