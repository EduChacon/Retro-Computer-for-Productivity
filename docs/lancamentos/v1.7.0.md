Retro Computer 1.7.0 brings organization: a Calendar with reminders, sticky notes on the desktop, photos from the phone over the local network, and the windows that were open coming back when you turn it on again.

## New

- **Calendar** (Start › Programs › Accessories): the month on the left and the day's events on the right (or the next 30 days). Each event has a title, a location, a start and an end (or all day), a repetition (every day, week, month or year, until a date), a reminder and notes; on an event that repeats, changing or deleting it asks whether it is only this occurrence or all of them. The events are kept in `Documents/Calendar.ics`, the same format as Google Calendar, Outlook and the Mac Calendar, and each change keeps the previous version. Opening another `.ics` file (from an invitation, for example) imports its events, without changing the original file; the finer repetition rules the Calendar cannot open go back into the file as they came.
- **Reminders**, even with the Calendar closed: a window with Snooze (5 minutes to 1 hour) and Dismiss, and a bell sound; with "Do not disturb" on, only in the tray's bell. The clock's calendar marks the days with events and shows today's; clicking a day opens the Calendar on it.
- **Sticky notes** (Start › Programs › Accessories, or right-clicking the desktop): yellow papers between the icons and the windows. Each note is a `.txt` in `Documents/Sticky Notes` that saves itself while you type; the + creates another, the … changes the color (yellow, green, blue, pink, lilac or white) and opens the note in Notepad, and the × sends it to the Trash. From Start, the notes come in front of the windows until the next click outside them.
- **Receive from Phone** (Start › Programs › Accessories): a QR code for the phone to open, on the same Wi-Fi. The computer asks before accepting each new device; once accepted, photos and files arrive in `Documents/Received`, without overwriting anything. The server exists only while the window is open, only on the local network, with a new code every time; it turns itself off after 15 minutes without use or after 20 attempts with a wrong code; it never reads anything from the computer; and it takes up to 4 GB per file and 20 GB per session.
- **Reopen at startup**: the windows that were open come back the next time, in the same place and size: Explorer in its folder, Notepad, the Image Viewer and the Media Player with their files, the Browser at the tab's address. Command Prompt, Claude, DOS and the Mac Plus stay out. Control Panel › Appearance › Settings turns it off.
- **Claude and the Calendar**: in the Command Prompt, Claude can see and add appointments (the `agenda_ver` and `agenda_marcar` tools).

## Fixed

- On Linux, changes made by another program to a file that Retro Computer had saved before were not noticed (Node's recursive file watcher stays on the old file after a safe save), so Explorer, the Calendar and the notes did not update. Retro Computer now watches each folder on Linux.

Retro Computer 1.0 or later installed with the Windows installer or the AppImage updates itself on restart; the `.deb` asks for the administrator password, and on macOS the notice opens the download page. The installers are not digitally signed yet: on macOS, System Settings › Privacy & Security › Open Anyway the first time; on Windows, "More info" › "Run anyway". The first time Receive from Phone is used, Windows and macOS may ask whether Retro Computer can accept network connections: allow it only on private networks.
