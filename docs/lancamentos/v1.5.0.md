Retro Computer 1.5.0 adds Disks: formatting USB drives on every system, writing `.iso` and `.img` images to them, and the disk space of drive C: with a cleanup.

## New

- **Disks** (Start › Programs › Accessories): the USB drives, memory cards and hard disks connected by USB, whole, with the partitions under each one, including the ones with no letter or name, such as those of a USB drive with Linux written to it. Only USB disks and removable cards are listed for erasing: the system disk and the one that holds drive C: or Retro Computer itself (portable mode) appear grayed out and cannot be formatted or written.
- **Write image…**: an `.iso` or `.img` image from drive C: (such as Linux Mint's, to install Linux on a laptop) is written to the whole USB drive and then verified, piece by piece. The window shows the progress, the speed and the time left, and **Stop** interrupts it. The partition table is written last, after the rest has been verified, so the system does not mount the drive halfway through. Once written, the USB drive starts another computer: the MacBook Air guide (`docs/macbook-air.md`) can now be followed without balenaEtcher.
- **Disk space**: how much drive C: takes up, the folders that take up the most and the computer's free space. **Disk Cleanup** permanently deletes, after confirmation, only what you check: the Trash, previous versions older than 30 days, temporary Internet files (the Browser cache) and the Explorer thumbnails. Your files are not touched. Control Panel › Drive C: has a button that leads there.
- **File › System disk tool** opens the system's own (Disk Management on Windows, Disk Utility on the Mac, GNOME Disks on Linux), for what the program does not do.

## Improved

- **Format now works on Windows and on the Mac**, not only on Linux: Windows shows its own confirmation, and the Mac asks for its password if it needs to (on Linux, the administrator password, as before). The box also offers NTFS on Windows and **Use the whole USB drive**, which deletes all the partitions and creates a single one: this is how a USB drive that received an image goes back to normal.
- On Windows, Computer also shows the USB drives and hard disks that Windows sees as fixed disks, and labels with accents show correctly.

The installers are not digitally signed yet: on macOS, System Settings › Privacy & Security › Open Anyway the first time; on Windows, "More info" › "Run anyway".
