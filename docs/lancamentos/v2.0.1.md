Retro Computer 2.0.1 fixes the Linux keyring box that froze the screen when the computer enters Retro Computer directly at power-on.

## Fixed

- **The "Unlock session keyring" box of Linux froze Retro Computer** (Retro Computer as the system, entering directly at power-on, without the sign-in screen). With no password typed, the Linux keyring (GNOME Keyring), which keeps the Browser cookies and the Claude key, stays locked, and the first question Retro Computer asked it opened the system's own box and stopped Retro Computer until it was answered: the screen was not redrawn, and dragging the box left trails across it. Now Retro Computer sees that the keyring is locked when it opens, without asking the keyring anything, and asks for your Linux sign-in password in a box of its own (**Linux Keyring**), in the period style. With the password, the keyring is unlocked the same way the sign-in screen does it. The password typed on the lock screen unlocks it too.
- If you cancel the box, the computer works as usual and nothing asks for the password behind it: the Claude key waits (Control Panel › Claude › **Unlock the Keyring…**), and the Security Center shows "Keyring locked".
