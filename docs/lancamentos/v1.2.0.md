Retro Computer 1.2.0 lets you use your own pictures as the wallpaper.

## New

- **Wallpaper with your own image**: Control Panel › Appearance › Background has a Wallpaper box. **Browse…** picks an image from drive C: (PNG, JPEG, GIF, WebP or BMP, up to 50 MB), and **Fit** shows it centered (one image pixel per screen pixel, with the color and the pattern around it), tiled, or filling the screen without stretching. In the Explorer, right-click an image › **Set as desktop background** does the same. Retro Computer keeps a copy of each image in the user's own data folder, so the wallpaper stays even if the file on drive C: is moved or deleted; **Remove…** takes the image off the list and deletes only that copy. Each user has their own wallpapers. No images come with Retro Computer: the list starts empty.
