Retro Computer 2.2.1 fixes Codex installation on Windows and keeps dot conversations inside the app.

- **Codex on Windows:** Install now uses `winget install --id OpenAI.Codex --exact --source winget`, which installs the official OpenAI binary with package verification. This avoids the `OSArchitecture` property error in some Windows PowerShell 5.1 installations. If winget is unavailable, install or update App Installer from the Microsoft Store. macOS and Linux retain the official OpenAI installer.
- **Find Codex after installation:** Retro Computer also checks the winget links and the standalone installer's current Windows location, so opening Codex again can find it before the app inherits the updated PATH.
- **Your dot inside Retro:** Open my dot and Official help open in the integrated Retro Computer Browser, including when Firefox or an external browser is preferred for other links. The official page handles your existing account and dot. It remains isolated from Retro Computer's command bridge. Local dot access still depends on the separate connection in the official ChatGPT app.
- **System integration:** Codex retains the same Retro Computer MCP tools available to Claude Code. The packaged-app checks now exercise appearance changes, a desktop shortcut and Calendar access, in addition to login, resume, file history and argument handling. The Windows workflow installs the real CLI using Windows PowerShell 5.1 and runs `codex --version` with the PATH from before installation, without account sign-in or model calls.

Install this version over your existing Retro Computer installation. Your drive C: files, settings and Codex credentials stay in their existing locations.
