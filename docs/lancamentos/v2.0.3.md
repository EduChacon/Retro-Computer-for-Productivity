Retro Computer 2.0.3 removes the white border around Firefox in full screen and makes all the laptop's function keys work when Retro Computer is the system, including the keyboard backlight.

## New

- **The laptop's function keys** (Retro Computer as the system) work with any window in front, also a Linux program's:
  - screen brightness;
  - the **keyboard backlight** (F5 and F6 on a MacBook, or the on/off key of other laptops), with a slider in the battery box of the notification area too;
  - media: back, play or pause and forward go to the program that is playing (Firefox, the Browser, the Media Player);
  - Task View (F3 on a MacBook), Start (F4) and the Calculator.
- **The power button opens the Shut Down box.** Before, it turned the computer off at once, without saving anything. With the screen locked, it puts the computer to sleep. Holding the button for a few seconds still forces it off.

## Fixed

- **A white border around Firefox in full screen** (a video or F11). The sunken frame around the page, new in 2.0.2, stayed in full screen; now the page goes to the edge of the screen.
