Retro Computer 1.8.0 brings virtual desktops with Task View, an emoji panel and color schemes, including dark ones.

## New

- **Virtual desktops**, as in today's Windows: Logo+Ctrl+D creates a desktop (or right-click the taskbar › New desktop), Logo+Ctrl+← and → switch desktops (its name appears in the middle of the screen for a moment) and Logo+Ctrl+F4 closes the current one, whose windows go to the desktop beside it. The taskbar and Alt+Tab show only the windows of the desktop in view; with more than one desktop, a button for each one sits next to the tray (in the Mac theme, next to the clock). Right-clicking a window's button › Move to takes it to another desktop, and Reopen at startup brings back the desktops and each window to its own. Up to eight desktops.
- **Task View** (Logo+Tab, or right-click the taskbar): one column per desktop, with its windows. A click on a window goes to it; dragging a window to another column takes it to that desktop.
- **Emoji panel** (Logo+. or Logo+;, or Start › Programs › Accessories › Emoji): search by name in English, Portuguese or Spanish, without needing the accents, browse the categories or pick from the recently used ones; a click puts the emoji in the field that had the focus (a field on the desktop, a Craft program, the Command Prompt or a page in the Browser), or on the clipboard when there is none. The drawings are SerenityOS's pixel-art emoji; the names come from the Unicode CLDR.
- **Color schemes** (Control Panel › Appearance › Theme › Color scheme), with a preview: the usual one, seven light ones (Sand, Slate, Eggplant, Moss, Ocean, Brick and Old rose) and four dark ones (Night, Midnight, Green phosphor and Amber), which make the windows, the fields and the lists dark, with light text. Documents in the preview stay on white paper. The schemes apply to the Classic PC theme; Claude can change them too.
- **iPhone and iPad**: the installation guide explains how to try the Linux session in UTM SE (slow, since the App Store version has no JIT).

## Fixed

- In the Classic Mac theme, the small square of the zoom box is now in the middle of the box.

Retro Computer 1.0 or later installed with the Windows installer or the AppImage updates itself on restart; the `.deb` asks for the administrator password, and on macOS the notice opens the download page. The installers are not digitally signed yet: on macOS, System Settings › Privacy & Security › Open Anyway the first time; on Windows, "More info" › "Run anyway". When Retro Computer runs as an application, Windows and macOS keep some logo-key shortcuts for themselves (Windows has its own virtual desktops on Logo+Ctrl+D): the taskbar menu and Task View work everywhere.
