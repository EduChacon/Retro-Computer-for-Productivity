Retro Computer 2.0.2 makes Firefox, the default browser, look and size like Retro Computer's own Browser, and keeps Retro Computer's mouse pointer in the Linux programs.

## Fixed

- **Firefox was far too big.** The pixel size of Control Panel › Appearance was counted twice for Firefox: at 1.25 it opened at 2, and at 2 it opened at 4. Now Firefox uses exactly the pixel size of the desktop.
- **Firefox looked out of place.** Its top bar now follows Retro Computer's Browser: the menu bar (File, Edit, View, History, Bookmarks, Tools, Help), the straight tabs with the period × and +, the same 16-pixel icons for back, forward, reload, home and downloads, the sunken address field and the bookmarks bar with the folder icons, in the gray and the period font. If you hide the menu bar or the bookmarks bar in Firefox itself, they stay hidden.
- **The mouse pointer changed inside the Linux programs** (Retro Computer as the system). Firefox, LibreOffice and the other Linux programs, and the edges of their windows, used the pointer of the Linux theme (the Linux Mint one, for example). Now they use the same pointer as the desktop. The window edges change at the next sign-in; the programs opened by Retro Computer change right after the update.
