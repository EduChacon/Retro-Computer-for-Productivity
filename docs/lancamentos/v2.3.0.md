Retro Computer 2.3.0 introduces an animated desktop companion with an integrated chat powered by your choice of Claude Code or Codex.

## Eight companions

Choose Little Monitor, Little Floppy, Pocket Robot, Little Folder, Little Mouse, Terminal Cat, Coffee Buddy or Enamel Mug. Each has eight original transparent pixel-art poses, animated for idle, thinking, working, answering, waiting, success, rest and errors. Move the companion around the desktop and choose its size. Animations can be disabled and respect the operating system's reduced-motion preference. Selecting a character never starts a model request.

## Chat and actions inside Retro

- Open **Retro Assistant** from Start, the desktop icon or the companion. Pick **Claude Code** or **Codex** independently of the character. Existing terminal interfaces remain available.
- The chat streams responses, keeps conversation history in the user's Retro profile and supports resuming provider sessions. Closing the chat keeps an ongoing task available through the companion; exiting Retro stops the agent process.
- Attach up to eight files or folders from drive C:, including by dragging them onto the companion. Existing attached files receive a previous-version copy before a task starts. **Ask the assistant** in the file menu opens the chat with that selection.
- **Ask for help** in the programming lab shares the current code only when the user sends the message, with a suggested tutoring request.
- The optional Retro MCP connection supports the same system tools available to the existing Claude/Codex terminals. The chat displays tool activity, approval requests and questions. Allow once, decline or stop the task directly in the app. Native provider permission settings are preserved; no sandbox or approval bypass is added. Turning off system adjustments closes the current agent connection.

Install and authenticate the selected official CLI using **Installation and account**. Accounts, available models and usage limits remain with the provider. The mascot is a Retro assistant with its own conversation history.

Removed the Dot web-launcher application. Existing desktop and taskbar references migrate to the native assistant while preserving other choices; old shortcut files also open the new chat inside Retro Computer.

## Validation

Automated tests exercise both CLI protocols with local provider fixtures, including real Retro MCP changes, streaming, approvals, questions, cancellation, credential isolation, literal requests and previous file versions. They do not sign into real accounts or call paid models. The packaged Windows and macOS apps exercise the eight companions, animation/reduced-motion behavior and chat flows too.
