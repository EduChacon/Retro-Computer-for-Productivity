Retro Computer 2.2.0 adds Codex alongside Claude Code, plus access to the OpenAI dot on your ChatGPT account.

## New

- **Codex**, in Start and on the default desktop, opens the native **Codex CLI** in a retro terminal window on Windows, macOS and Linux. Existing customized desktops keep their choices; Codex can be added from Start.
- The first-run window offers the **official OpenAI installer**. Sign in with your ChatGPT account through the CLI. Account and options provides regular sign-in, device-code sign-in and a conversation picker. Device-code sign-in may need to be enabled in account security settings.
- Right-click a folder to **Open Codex here**, or a file to **Ask Codex** for a review, summary, translation or another request. The current file version is saved before opening the agent.
- The optional Retro Computer MCP connection gives Codex the same appearance, shortcuts, programs and Calendar tools available to Claude. It applies only to the current session and does not rewrite the user's Codex configuration. The MCP token stays out of process arguments. Turning the option off applies to new sessions.
- Codex keeps its own credentials and conversation history. Retro Computer does not read authentication files or pass the Claude API key to Codex. Native CLI permissions and approval settings are preserved.
- Codex receives its arguments directly, without a shell. Quoted requests, shell metacharacters and messages starting with option-like text remain literal input. The npm CLI wrapper can use Electron's Node runtime, including when the Finder does not inherit the Node installation's PATH.

Codex CLI is installed separately and is not bundled. Access, authentication methods and usage limits depend on the user's OpenAI account. This is an integration inside Retro Computer, not a copy of the official OpenAI desktop app.

## OpenAI dot

- **Dot** opens the official `chatgpt.com/dots` page and can launch the installed ChatGPT app to set up local computer access. It also shows the real drive C: folder and links to the official connection guide.
- The ChatGPT desktop app controls local authorization. Opening the dot's conversation or connecting Codex does not grant dot access to the computer. Availability depends on the user's account and region.
- This is access to the official service and guidance for connecting the local computer, not an embedded dot runtime or a private API integration. Account credentials and permissions remain with ChatGPT.

## Validation

The automated Codex checks use a local test CLI, without signing into accounts or calling models. They exercise argument handling, the selected working folder, login and resume actions, the real Retro Computer MCP server, the opt-out control, and previous versions for file requests. The packaged Windows and macOS apps run these checks too.
