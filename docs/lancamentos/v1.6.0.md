Retro Computer 1.6.0 brings PDF and paperwork tools: Save as PDF, PDF tools, scanning, copying the text of photos and scanned pages (OCR), searching inside documents, tabs in Explorer and a quick look on the space bar.

## New

- **Save as PDF**: in Notepad, the Image Viewer and the Browser, File › Save as PDF… saves the page (the same as the printout) to a PDF on drive C:, with no printer. The paper follows the country: Letter in the United States, Canada and Mexico; A4 elsewhere.
- **PDF tools**: right-click a PDF › PDF tools to **split it into pages** (one PDF per page, in a new folder), **extract pages** (such as `1-3, 5`) into a new PDF or **rotate** it; on an image, **Convert to PDF**; on several files, **Combine into one PDF…**. The **PDF Tools** window (Start › Programs › Accessories) puts PDFs and images in the order you want before combining. The original never changes; Rotate saves over the file and keeps the previous version. PDFs with a password or protected against changes are refused with a notice.
- **Copy the text (OCR)**: right-click a photo, a scan or a PDF (or Edit in the Image Viewer) and the text appears in a window, ready to copy or save as `.txt`, in Portuguese, English or Spanish. In PDFs, the pages that already have text give their own text; the scanned ones are read by Tesseract. Everything runs on the computer, offline.
- **Scan** (Start › Programs › Accessories): choose the scanner, the color and the resolution and scan one page at a time; the pages go together into a PDF or as images, with the OCR right after, if checked. On Linux it uses SANE (network scanners through eSCL with `sane-airscan`); on Windows, WIA; on the Mac, the button opens the system's Image Capture.
- **Search inside files**: the taskbar search box (under "Inside files", with the excerpt found) and Find (the new "Containing" field) also look inside text files, Word, OpenDocument, Excel, PowerPoint, RTF and PDF documents, ignoring accents and capitals, with all the words or an exact phrase in quotation marks. The text of each document is kept in an index in the user's data folder, updated bit by bit when drive C: changes; Control Panel › Drive C: › Search turns it off, which deletes the index. Nothing leaves the computer.
- **Tabs in Explorer**: Ctrl+T opens a tab, Ctrl+W closes it, Ctrl+Tab moves to the next one, and right-clicking a folder offers "Open in new tab". Each tab keeps its own folder and history.
- **Quick look**: the space bar on a file in Explorer opens the preview pane in a big window; the arrows move to the next file, Enter opens it, and the space bar or Esc close it.

## Improved

- Everything that reads files from outside (the PDF tools, the OCR and the text for the search) runs in a separate worker process, with time and memory limits, so a broken or malicious file cannot freeze the desktop.
- With a dialog box open, the keyboard focus stays in it: pressing Enter in a dialog that opened right after another one no longer reaches the Explorer window behind it.
