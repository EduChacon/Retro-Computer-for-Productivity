# Retro Computer 2.5.0

Open compatible desktop apps with Retro's frame on Windows, and manage Mac app windows from Retro.

- **Computer programs › Open integrated…** adds experimental Windows integration for compatible windows. The original app content stays intact inside a frame that follows Retro's theme. Choose a window when an app has several, and save the opening preference per app.
- **Leave integration**, including the frame's close button, restores the original window and keeps the app running. **Close app…** uses the app's normal close request, preserving its save and cancel dialogs.
- On **Mac**, an Accessibility permission granted by the user enables focus, minimize, close and side-by-side controls. Native Mac windows keep their original frames; this mode does not claim to embed them.
- Link an app's **HTTPS web version** to open it entirely inside Retro on Windows, Mac and Linux. The normal host-computer opening option remains available.
- No additional npm dependencies, no changes to third-party app executables, and no forced termination of app processes. Includes Portuguese, English and Spanish UI, recovery behavior and native-window checks.

See [the integrated apps guide](../programas-integrados.md) for compatibility, permissions and validation limits.
